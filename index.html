账号与同步

AI 引擎

填写你自己的 API Key，费用直接算在你自己的账号上（DeepSeek 记单词这点用量约几分钱/月）。Key 只存在本机浏览器里，不会上传到任何第三方服务器。

常用地址： DeepSeek 官方 https://api.deepseek.com · OpenAI https://api.openai.com/v1 · 第三方网关（New API / One API）一般要填到 /v1 为止，例如 https://你的域名/v1。 填错了应用会自动再试一次加 /v1 的地址。

关于

精读 LexiRead 是一个纯本地的 PWA：没有服务器、没有账号、没有订阅。 在 iPhone / iPad 上用 Safari「分享 → 添加到主屏幕」即成为全屏 App；在 Mac 的 Safari 里「文件 → 添加到程序坞」同样得到独立窗口。
